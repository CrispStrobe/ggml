# CrispASR carried-patch manifest
#
# Every line is a patch this fork carries on top of upstream ggml, expressed as
# an executable check so that "MUST RE-APPLY after ggml bump" is enforced by CI
# instead of remembered by a human. It exists because it was NOT remembered: a
# core_adaln ARM failure survived for weeks because the vendored tree predated
# two upstream SVE fixes, and nobody was watching.
#
# Format:  <min-count> <TAB> <file> <TAB> <fixed-string pattern>
# A patch whose count drops below <min-count> fails the build.
#
# When an upstream merge legitimately removes or renames a patch, update this
# file IN THE SAME COMMIT and say why in the message. Editing it to make CI
# green without that justification defeats the entire point.
